\section*{1. Problem Statements and Requirements}
\noindent\rule{\textwidth}{0.5pt}\vspace{0.15cm}

\subsection*{Task 1: Student Result Management System}
\textbf{Problem Statement:} Design a system to manage student results. Each student has a name, ID, and a list of subjects with marks. The system should calculate the average and determine the grade (A, B, C, F).\\
\textbf{Requirements:}
\begin{itemize}
    \setlength{\itemsep}{2pt}
    \item Create a \texttt{Student} class.
    \item Create a \texttt{Subject} class.
    \item Add methods to calculate average and grade.
    \item Display student details with results.
\end{itemize}

\vspace{0.25cm}
\subsection*{Task 2: University Course Registration}
\textbf{Problem Statement:} Create a system where students can register for courses. Each course has a code, title, and credit hours. Students can register for multiple courses.\\
\textbf{Requirements:}
\begin{itemize}
    \setlength{\itemsep}{2pt}
    \item Create \texttt{Course} and \texttt{Student} classes.
    \item Add registration logic (including preventing duplicate registration).
    \item Display registered courses and total credits.
\end{itemize}

\vspace{0.25cm}
\subsection*{Task 3: Hospital Appointment Scheduler}
\textbf{Problem Statement:} Build a system to schedule appointments between patients and doctors. Each doctor has a name, specialization, and available slots. Patients can book appointments.\\
\textbf{Requirements:}
\begin{itemize}
    \setlength{\itemsep}{2pt}
    \item Create \texttt{Doctor} and \texttt{Patient} classes.
    \item Implement appointment booking.
    \item Prevent double booking.
    \item Display appointment summary.
\end{itemize}

\section*{2. Summary \& Key Findings}
\noindent\rule{\textwidth}{0.5pt}\vspace{0.15cm}
All three laboratory tasks were implemented in Dart using clean object-oriented principles:
\begin{itemize}
    \setlength{\itemsep}{4pt}
    \item \textbf{Task 1 (Student Result System):} Demonstrates class encapsulation and aggregation by maintaining subjects within a student entity and dynamically computing weighted averages and letter grades.
    \item \textbf{Task 2 (Course Registration):} Employs multi-object association and enrollment verification logic to prevent duplicate registrations and compute cumulative credit totals.
    \item \textbf{Task 3 (Hospital Scheduler):} Utilizes list membership checks and key-value mapping to manage appointment allocations, successfully preventing double-booking on occupied slots.
\end{itemize}
