\section*{1. Problem Description}
\noindent\rule{\textwidth}{0.5pt}\vspace{0.15cm}

This lab task involves creating a simple backend system for a Digital Wallet application in Dart. The application manages two forms of bank accounts: \textbf{Standard Accounts} and \textbf{Premium Accounts}. The core business logic specifies that premium account holders receive an automatic cash-back bonus whenever funds are deposited into their account.

\vspace{0.25cm}
\section*{2. Architecture and Technical Requirements}
\noindent\rule{\textwidth}{0.5pt}\vspace{0.15cm}

\begin{enumerate}
    \setlength{\itemsep}{7pt}
    \item \textbf{Encapsulation (\texttt{BankAccount}):}
    \begin{itemize}
        \item Create a base class named \texttt{BankAccount}.
        \item Store balance in a private variable (\texttt{\_accBalance}).
        \item Provide a public getter (\texttt{get balance}) to read balance without direct external modification.
        \item Implement a \texttt{deposit(double amount)} method to handle fund deposits safely.
    \end{itemize}
    \item \textbf{Inheritance and Polymorphism (\texttt{PremiumAccount}):}
    \begin{itemize}
        \item Implement a derived class \texttt{PremiumAccount} that extends \texttt{BankAccount}.
        \item Override \texttt{deposit(double amount)} so that premium customers automatically receive an additional \textbf{5\% cash-back bonus} on every deposit.
    \end{itemize}
\end{enumerate}

\vspace{0.35cm}
\section*{3. Design and Logic Explanation}
\noindent\rule{\textwidth}{0.5pt}\vspace{0.15cm}

\begin{itemize}
    \setlength{\itemsep}{4pt}
    \item \textbf{Encapsulation Mechanism:} By applying the underscore prefix (\texttt{\_accBalance}), the field is scoped library-private. External code cannot directly overwrite the balance, ensuring validation rules remain intact.
    \item \textbf{Inheritance Model:} \texttt{PremiumAccount} reuses the base balance management logic from \texttt{BankAccount} without redundant code.
    \item \textbf{Polymorphic Bonus Addition:} In \texttt{PremiumAccount}, the \texttt{deposit} method calculates the cash-back bonus:
    \[
        \text{Cashback} = \text{amount} \times 0.05
    \]
    The total amount credited to the account becomes $\text{amount} + \text{Cashback}$, which is handed over to \texttt{super.deposit(amount + cashback);}.
\end{itemize}
