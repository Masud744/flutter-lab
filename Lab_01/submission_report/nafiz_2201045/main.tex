\section*{1. Task Overview and Objectives}
\noindent\rule{\textwidth}{0.5pt}\vspace{0.15cm}

The task requires designing a lightweight backend architecture for a Digital Wallet application in Dart. The system must support two account categories: \textbf{Standard Accounts} and \textbf{Premium Accounts}. While standard accounts handle regular deposits, premium accounts offer incentive rewards by providing an automated cash-back on every deposit transaction.

\vspace{0.25cm}
\section*{2. Architectural Specifications}
\noindent\rule{\textwidth}{0.5pt}\vspace{0.15cm}

\begin{itemize}
    \setlength{\itemsep}{8pt}
    \item \textbf{Encapsulation (\texttt{BankAccount}):}
    \begin{itemize}
        \item Define a base class named \texttt{BankAccount}.
        \item Encapsulate the balance field by making it private (\texttt{\_currentBalance}).
        \item Provide a public getter (\texttt{balance}) to access the funds without allowing external direct writes.
        \item Create a \texttt{deposit(double amount)} method to handle account deposits.
    \end{itemize}
    \item \textbf{Inheritance \& Polymorphism (\texttt{PremiumAccount}):}
    \begin{itemize}
        \item Create a subclass \texttt{PremiumAccount} inheriting from \texttt{BankAccount}.
        \item Override the \texttt{deposit(double amount)} method so that premium users automatically earn a \textbf{5\% cash-back reward} on their deposited amount.
    \end{itemize}
\end{itemize}

\vspace{0.35cm}
\section*{3. Technical Approach}
\noindent\rule{\textwidth}{0.5pt}\vspace{0.15cm}

\begin{itemize}
    \setlength{\itemsep}{4pt}
    \item \textbf{Data Hiding:} In Dart, private members are declared with an underscore (\texttt{\_}). By declaring \texttt{\_currentBalance}, direct assignment from outside the class is prevented. Read-only access is provided by \texttt{double get balance => \_currentBalance;}.
    \item \textbf{Inheritance Structure:} The \texttt{PremiumAccount} class extends \texttt{BankAccount}, utilizing inherited behaviors and attributes.
    \item \textbf{Method Overriding:} The \texttt{deposit} method is marked with \texttt{@override}. The extra cash-back reward is computed as:
    \[
        \text{Reward} = \text{amount} \times 0.05
    \]
    The updated deposit amount including reward is then forwarded to \texttt{super.deposit(amount + reward);}.
\end{itemize}
