## Lab Problems and Implementation

### Problem 1: List of Names
Create a list of names and print all names using list.
- File: [`src/problem1_names_list.dart`](src/problem1_names_list.dart)
- Run: `dart run src/problem1_names_list.dart`

### Problem 2: Set of Fruits
Create a set of fruits and print all fruits using loop.
- File: [`src/problem2_fruits_set.dart`](src/problem2_fruits_set.dart)
- Run: `dart run src/problem2_fruits_set.dart`

### Problem 3: Expenses Total
Create a program that reads list of expenses amount using user input and print total.
- File: [`src/problem3_expenses.dart`](src/problem3_expenses.dart)
- Run: `dart run src/problem3_expenses.dart`

### Problem 4: Days of the Week
Create an empty list of type string called days. Use the add method to add names of 7 days and print all days.
- File: [`src/problem4_days_list.dart`](src/problem4_days_list.dart)
- Run: `dart run src/problem4_days_list.dart`

### Problem 5: Capitalize Words in File
Read data from a file and capitalized each word and write the result in separate file. Both file should be in same format.
- File: [`src/problem5_file_capitalize.dart`](src/problem5_file_capitalize.dart)
- Run: `dart run src/problem5_file_capitalize.dart`

### Problem 6: Map Key Update
Create a map with name, address, age, country keys and store values to it. Update country name to other country and print all keys and values.
- File: [`src/problem6_person_map.dart`](src/problem6_person_map.dart)
- Run: `dart run src/problem6_person_map.dart`

### Problem 7: Filter Map Keys with `where`
Create a map with name, phone keys and store some values to it. Use where to find all keys that have length 4.
- File: [`src/problem7_phone_map.dart`](src/problem7_phone_map.dart)
- Run: `dart run src/problem7_phone_map.dart`

### Problem 8: Simple To-Do Application
Create a simple to-do application that allows user to add, remove, and view their task.
- File: [`src/problem8_todo_app.dart`](src/problem8_todo_app.dart)
- Run: `dart run src/problem8_todo_app.dart`
