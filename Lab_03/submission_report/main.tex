\section*{Laboratory Objectives and Problem Overview}
\noindent\rule{\textwidth}{0.5pt}\vspace{0.15cm}

This laboratory module focuses on fundamental data structures and input/output systems in the Dart programming language, essential for building mobile applications on Flutter. The tasks cover:
\begin{enumerate}
    \setlength{\itemsep}{3pt}
    \item \textbf{Problem 1:} Create a list of names and print all names using list.
    \item \textbf{Problem 2:} Create a set of fruits and print all fruits using loop.
    \item \textbf{Problem 3:} Create a program that reads list of expenses amount using user input and print total.
    \item \textbf{Problem 4:} Create an empty list of type string called \texttt{days}. Use the \texttt{add} method to add names of 7 days and print all days.
    \item \textbf{Problem 5:} Read data from a file, capitalize each word, and write the result into a separate file in the same format.
    \item \textbf{Problem 6:} Create a map with \texttt{name}, \texttt{address}, \texttt{age}, \texttt{country} keys and store values to it. Update country name to another country and print all keys and values.
    \item \textbf{Problem 7:} Create a map with contact names and phone keys, and use \texttt{where} to find all keys that have length 4.
    \item \textbf{Problem 8:} Create a simple to-do application that allows the user to add, remove, and view their tasks.
\end{enumerate}
